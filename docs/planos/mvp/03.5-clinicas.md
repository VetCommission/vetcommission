# 03.5 — Clínicas do tenant

**Objetivo:** permitir que um tenant/empresa administre uma ou mais clínicas e que os dados operacionais sejam vinculados à clínica correta.

**Dependência:** 02 — Identidade, tenant e acesso.

## Escopo

- cadastro de clínicas dentro do tenant;
- listagem, detalhe, criação, edição e inativação;
- seleção de clínica ativa no contexto operacional;
- isolamento por `tenant_id` e `clinic_id`;
- clínica única selecionada automaticamente;
- permissões próprias do domínio;
- navbar, Home, lista, formulário, detalhe e atualização automática seguindo o padrão da etapa 03.

## Impacto nos domínios já criados

Os cadastros operacionais deverão receber `clinic_id` obrigatório:

- profissionais;
- funções/cargos, se forem específicos da clínica;
- especialidades, se forem específicos da clínica;
- categorias;
- procedimentos;
- regras, produção e fechamento.

As tabelas e APIs existentes que usam somente `tenant_id` deverão receber migração corretiva versionada. Scripts já aplicados não serão alterados.

## Critérios de aceite

- usuário só consulta clínicas do tenant ativo;
- usuário só acessa dados operacionais da clínica ativa;
- troca de clínica invalida queries operacionais anteriores;
- tenant com uma única clínica seleciona o contexto automaticamente;
- tenant sem clínica recebe estado orientativo;
- nenhuma API aceita `clinic_id` de outro tenant.
