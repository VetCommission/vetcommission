# CHECKLIST DE REVISÃO UI/UX

## Identidade
- [ ] Paleta oficial aplicada.
- [ ] Tipografia consistente.
- [ ] Ícones seguem o mesmo estilo.
- [ ] Bordas e sombras consistentes.
- [ ] Status seguem as mesmas cores e nomes.

## Layout
- [ ] Título da página está claro.
- [ ] Ação principal está evidente.
- [ ] Filtros aparecem antes do conteúdo.
- [ ] Espaçamento é consistente.
- [ ] Conteúdo não está excessivamente comprimido.

## Formulários
- [ ] Campos possuem labels.
- [ ] Obrigatórios são claros.
- [ ] Erros são acionáveis.
- [ ] Dados não são perdidos após erro.
- [ ] Ações cancelar/salvar são inequívocas.

## Tabelas/listas
- [ ] Cabeçalho legível.
- [ ] Status com badge.
- [ ] Ações por item consistentes.
- [ ] Estado vazio existe.
- [ ] Filtros podem ser limpos.

## Estados
- [ ] Loading.
- [ ] Vazio.
- [ ] Sem resultado de filtro.
- [ ] Erro.
- [ ] Sucesso.
- [ ] Sem permissão, quando aplicável.
- [ ] Período fechado, quando aplicável.

## Responsividade
- [ ] Desktop validado.
- [ ] Tablet validado.
- [ ] Mobile validado.
- [ ] Área do profissional confortável no celular.
- [ ] Tabelas não ficam ilegíveis.

## Acessibilidade
- [ ] Contraste adequado.
- [ ] Foco visível.
- [ ] Não depende apenas de cor.
- [ ] Área de toque confortável.
- [ ] Termos consistentes.

## Negócio
- [ ] Valor da produção não é confundido com comissão.
- [ ] Regra aplicada pode ser entendida.
- [ ] Contestação sempre parte de um lançamento.
- [ ] Fechamento mostra pendências.
- [ ] Período fechado aparece somente leitura.
