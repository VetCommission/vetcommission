# CRITÉRIOS DE ACEITE VISUAL

## 1. Critérios globais

Uma tela só pode ser considerada visualmente concluída quando:

- segue a paleta oficial;
- segue a tipografia oficial;
- possui hierarquia clara;
- ação principal é identificável;
- estados de carregamento, vazio e erro existem;
- funciona em tamanhos previstos;
- labels e mensagens são legíveis;
- status não depende apenas de cor;
- navegação é consistente;
- mantém a mesma linguagem dos mockups aprovados.

## 2. Dashboard

Aceito quando:
- KPIs aparecem em primeiro nível;
- período é evidente;
- gráfico não domina a tela;
- valores podem ser entendidos sem abrir outra página;
- pendências importantes têm visibilidade.

## 3. Listagens

Aceito quando:
- filtros ficam antes da lista;
- ação de criar é fácil de localizar;
- status possui badge;
- ações por item estão agrupadas;
- retorno do detalhe preserva filtros.

## 4. Formulários

Aceito quando:
- labels persistem;
- obrigatórios são reconhecíveis;
- erros aparecem próximos;
- botão primário é claro;
- usuário não perde preenchimento em validação.

## 5. Produção

Aceito quando:
- cálculo estimado é visível antes da confirmação;
- valor total não é confundido com comissão;
- regra aplicada pode ser compreendida.

## 6. Contestação

Aceito quando:
- contexto do lançamento é visível;
- status é claro;
- histórico é compreensível;
- decisão administrativa sempre apresenta justificativa.

## 7. Fechamento

Aceito quando:
- competência é evidente;
- pendências aparecem antes da confirmação;
- consequência do fechamento é explicada;
- período fechado fica claramente somente leitura.

## 8. Portal do profissional

Aceito quando:
- comissão do período é encontrada rapidamente;
- detalhe explica cálculo;
- contestação pode ser iniciada a partir do lançamento;
- barra inferior mantém orientação;
- experiência funciona confortavelmente em celular.
