# PROMPT BASE PARA O CODEX — REPLICAÇÃO DO MVP UI/UX

Use os documentos deste pacote como fonte de verdade para comportamento de produto, organização visual e experiência do MVP.

## Objetivo

Construir as telas e fluxos respeitando integralmente:
- requisitos de negócio;
- design system;
- posicionamento;
- jornada administrativa;
- jornada do profissional;
- estados da interface;
- mensagens;
- responsividade;
- acessibilidade;
- critérios de aceite.

## Regras

- Não invente novas regras de negócio.
- Não altere nomenclaturas oficiais.
- Não introduza novas telas sem necessidade documentada.
- Não misture produção com comissão.
- Não esconda memória de cálculo quando ela for necessária à transparência.
- Preserve o contexto do usuário ao navegar entre lista e detalhe.
- Implemente estados de loading, vazio, erro e bloqueio.
- Garanta comportamento responsivo.
- Garanta consistência dos componentes entre telas.
- Trate os mockups como referência visual, não como substituto das regras escritas.

## Para cada tela

Antes de considerar concluída, confira:
1. objetivo;
2. perfil;
3. componentes;
4. ordem visual;
5. ação principal;
6. ações secundárias;
7. filtros;
8. estados;
9. mensagens;
10. responsividade;
11. critérios de aceite.

## Critério de conclusão

Uma tela só está pronta quando o usuário consegue realizar a tarefa prevista sem precisar inferir regra ou comportamento não explicado pela interface.
