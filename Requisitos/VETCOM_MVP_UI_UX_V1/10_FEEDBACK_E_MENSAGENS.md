# FEEDBACK, MICROCOPY E MENSAGENS

## 1. Tom de voz

- claro;
- respeitoso;
- direto;
- profissional;
- sem jargão técnico;
- sem frases alarmistas.

## 2. Verbos de ação

Preferir:
- Salvar
- Registrar produção
- Enviar contestação
- Aprovar
- Rejeitar
- Finalizar período
- Ver detalhes
- Limpar filtros

Evitar textos vagos como “OK” quando existe ação específica.

## 3. Exemplos de sucesso

- “Profissional cadastrado com sucesso.”
- “Produção registrada e comissão calculada.”
- “Contestação enviada para análise.”
- “Período finalizado com sucesso.”

## 4. Exemplos de atenção

- “Existem contestações em análise neste período.”
- “Revise os lançamentos antes de finalizar o período.”
- “Este profissional está inativo e não pode receber novas produções.”

## 5. Exemplos de erro

- “Não foi possível carregar as informações. Tente novamente.”
- “Informe todos os campos obrigatórios.”
- “Não existe uma regra de comissão válida para este lançamento.”

## 6. Confirmação destrutiva

Estrutura:
- título objetivo;
- consequência;
- botão cancelar;
- botão de confirmação explícito.

## 7. Fechamento

Mensagem sugerida:
“Após finalizar o período, os lançamentos ficarão disponíveis apenas para consulta no fluxo normal. Confirme somente após revisar produções, comissões e contestações.”

## 8. Contestação rejeitada

A justificativa deve ser exibida de forma neutra e completa, sem linguagem de confronto.

## 9. Empty state

Deve orientar o próximo passo:
“Nenhuma produção registrada. Registre a primeira produção para iniciar o cálculo das comissões.”

## 10. Ajuda contextual

Usar textos curtos junto a conceitos que podem gerar dúvida:
- vigência;
- regra específica;
- valor fixo;
- fechamento.
